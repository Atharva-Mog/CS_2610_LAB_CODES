# CS_2610_LAB_CODES

This repository contains CS-2610 (Computer Architecture Lab) submissions in RISC-V assembly, along with reports and generated artifacts.

## Extracted lab folders

The zip files have been extracted and normalized to a consistent naming format: `labN_cs23b096`.

- `lab1_cs23b096` - RISC-V assembly basics (introductory programs and Lab 1 report).
- `lab2_cs23b096` - Multi-precision arithmetic tasks with assembly source, dumps/executables, and report.
- `lab4_cs23b096` - C and assembly interfacing exercises (Q1/Q2 source, dumps, executable, and report).
- `lab5_cs23b096` - Privilege switching in RISC-V with linker script, assembly source, dump, executable, and report.
- `lab6_cs23b096` - Timer interrupts and context switching with template/source files, linker script, dumps/executables, and report.
- `lab7_cs23b096` - Virtual memory management lab with template/linker files, assembly source, dump/executable, and report.
- `lab8_cs23b096` - Page-fault handling lab with template/linker files, dump/executable, and report.
